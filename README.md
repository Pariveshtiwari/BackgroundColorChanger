# BackgroundColorChanger
🎨 Background Color Changer

📜 Description

The Background Color Changer is a simple JavaScript project that dynamically changes the background color of a webpage when a button is clicked. This project is perfect for beginners to understand the fundamentals of JavaScript, event listeners, and DOM manipulation.

🚀 Features

Change the background color with a single click.
Random hexadecimal color generation using the Math module.
Beginner-friendly and easy to understand.
🛠️ Technologies Used

HTML: For structuring the button and webpage.
CSS: For basic styling of the webpage and button.
JavaScript: For functionality and dynamic color changes.
📂 File Structure

project-folder/
├── index.html      # HTML structure for the webpage
├── style.css       # Styling for the webpage and button
